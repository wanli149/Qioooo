# QIoooo 主题常见问题

## 安装和激活

### 1. 如何安装主题？

您可以通过以下两种方式安装主题：

1. **通过 WordPress 后台安装**：
   - 进入"外观" > "主题"
   - 点击"添加新主题"
   - 点击"上传主题"
   - 选择主题包并安装

2. **通过 FTP 安装**：
   - 解压主题包
   - 上传到 `wp-content/themes/` 目录
   - 在后台启用主题

### 2. 主题激活后出现白屏？

可能的原因：
- PHP 版本过低
- 内存限制不足
- 插件冲突

解决方案：
1. 检查 PHP 版本（需要 7.4+）
2. 增加 PHP 内存限制
3. 停用其他插件测试

## 主题设置

### 1. 如何更改主题颜色？

1. 进入"外观" > "自定义" > "颜色"
2. 设置您喜欢的颜色
3. 点击"发布"保存更改

### 2. 如何启用暗黑模式？

1. 进入"外观" > "主题设置"
2. 找到"暗黑模式"选项
3. 选择"自动"、"开启"或"关闭"

### 3. 如何自定义布局？

1. 进入"外观" > "主题设置" > "布局"
2. 设置页面宽度
3. 设置侧边栏位置
4. 自定义页眉和页脚

## 功能使用

### 1. 如何添加自定义菜单？

1. 进入"外观" > "菜单"
2. 创建新菜单
3. 添加菜单项
4. 设置菜单位置

### 2. 如何添加小工具？

1. 进入"外观" > "小工具"
2. 拖放小工具到侧边栏
3. 配置小工具选项
4. 保存更改

### 3. 如何添加自定义 CSS？

1. 进入"外观" > "自定义" > "额外 CSS"
2. 添加您的 CSS 代码
3. 点击"发布"保存更改

## 性能优化

### 1. 如何提高网站加载速度？

建议：
- 使用缓存插件
- 优化图片大小
- 启用延迟加载
- 使用 CDN

### 2. 如何减少数据库查询？

建议：
- 使用对象缓存
- 优化查询语句
- 定期清理数据库
- 使用静态页面

### 3. 如何优化移动端性能？

建议：
- 使用响应式图片
- 优化 CSS 和 JavaScript
- 减少 HTTP 请求
- 使用移动端缓存

## 安全性

### 1. 如何保护网站安全？

建议：
- 使用 HTTPS
- 定期更新主题和插件
- 使用强密码
- 限制登录尝试

### 2. 如何防止 XSS 攻击？

建议：
- 验证和清理输入
- 转义输出
- 使用 nonce
- 设置安全头

### 3. 如何备份网站？

建议：
- 使用备份插件
- 定期手动备份
- 存储多个备份副本
- 测试备份恢复

## 故障排除

### 1. 主题更新后出现问题？

解决方案：
1. 清除浏览器缓存
2. 清除 WordPress 缓存
3. 检查插件兼容性
4. 恢复备份

### 2. 样式未正确加载？

解决方案：
1. 检查文件权限
2. 检查文件路径
3. 清除缓存
4. 检查控制台错误

### 3. 功能异常？

解决方案：
1. 检查错误日志
2. 停用其他插件测试
3. 检查主题设置
4. 联系技术支持

## 技术支持

### 1. 如何获取技术支持？

您可以通过以下方式获取支持：
- 查看主题文档
- 提交 GitHub Issue
- 发送邮件至 support@your-domain.com
- 加入用户社区

如果您发现安全漏洞，请：
1. 不要公开披露
2. 通过安全渠道报告
3. 提供详细复现步骤
4. 等待修复确认
