## 1. 快速入门

### 1.1 主题安装与激活

1. 登录您的 WordPress 后台
2. 导航至外观(Appearance) > 主题(Themes)
3. 点击顶部的添加新主题(Add New)按钮
4. 点击上传主题(Upload Theme)按钮
5. 选择您下载的 QIoooo.zip 文件，点击现在安装(Install Now)
6. 安装完成后，点击启用(Activate)

### 1.2 推荐与必需插件

QIoooo 主题的部分高级功能依赖于第三方插件。

**强烈推荐插件：**

- **SEO 插件**：建议安装 Yoast SEO 或 Rank Math 来处理网站地图、详细 Schema、索引规则等
- **页面缓存**：为了获得最佳性能，建议安装并配置 WP Rocket、W3 Total Cache 或 WP Super Cache
- **图片优化**：使用 Smush、ShortPixel 或类似插件压缩和优化图片

**可选插件：**

- **表单**：Contact Form 7、WPForms Lite（主题提供样式兼容）
- **社交登录**：WordPress Social Login（主题提供样式兼容）

## 2. 核心概念

### 2.1 "主题设置"面板详解

这是您配置 QIoooo 主题的主要场所。绝大部分的外观、布局、功能开关和详细设置都在这里完成。

**访问方式：**
- 登录后台后，点击左侧菜单的"QIoooo 设置"

**实用功能：**
- 搜索设置：面板顶部有搜索框，帮助您快速定位特定选项
- 导入/导出：在"高级选项"标签页中，您可以导出当前的所有设置以作备份，或导入之前保存的设置
- 重置设置：您可以重置所有设置为主题默认值，或者仅重置当前标签页的设置

### 2.2 响应式设计

QIoooo 主题采用响应式设计，能自动适应不同尺寸的设备屏幕（桌面、平板、手机），无需额外设置。部分布局选项允许您为不同设备单独设置。

### 2.3 功能模块化

为了保持主题核心的轻量和高性能，一些非必需的功能被设计为可选模块。您可以在"主题设置 > 常规设置 > 功能模块开关"中启用或禁用它们。禁用的模块不会加载任何相关代码或资源，不会影响网站性能。

## 3. "主题设置"面板详解

### 3.1 常规设置

- **站点标识**：上传 Logo 图片、设置文本 Logo 样式、上传 Favicon 等
- **功能模块开关**：启用或禁用可选功能
- **API 密钥**：如果集成了需要 Key 的第三方服务，在此输入

### 3.2 外观样式

- **色彩方案**：使用颜色选择器精细调整网站各个元素的颜色
- **排版**：选择全局字体，为标题、正文等分别设置字体、字重、大小等
- **界面元素**：统一设置按钮样式、表单风格、图片圆角等
- **背景**：设置全局或盒式布局下的背景色/图片

### 3.3 布局

- **主要宽度模式**：选择"内容定宽"、"全宽内容"或"盒式布局"
- **侧边栏布局**：设置全局默认侧边栏（左/右/无）

### 3.4 页头

- **布局预设**：选择一种页头结构
- **元素控制**：控制 Logo、菜单、搜索、社交图标等的显示和样式
- **粘性页头**：配置页头是否吸顶以及吸顶时的样式
- **移动端页头**：单独配置移动设备上的页头样式

### 3.5 页脚

- **小工具区域**：选择页脚小工具的列数
- **元素控制**：设置页脚菜单、社交图标、版权信息等
- **返回顶部**：启用并配置"返回顶部"按钮

### 3.6 博客/归档页

- **布局**：选择博客列表页的布局（经典、网格、列表等）
- **内容**：控制文章摘要显示方式、特色图片样式
- **元信息**：选择显示哪些文章信息
- **分页**：选择分页条的样式

### 3.7 单篇文章/页面

- **布局**：设置文章内容区域宽度、特色图片显示方式
- **元素控制**：控制面包屑、文章信息、作者框、相关文章等
- **内容增强**：配置图片灯箱、代码高亮、文章目录

### 3.8 用户体验增强

- **AJAX 功能**：开启列表加载、评论提交、搜索等 AJAX 功能
- **导航增强**：启用阅读进度条
- **图片处理**：配置内置图片灯箱效果

### 3.9 SEO 设置

- **插件推荐**：建议使用 Yoast SEO 或 Rank Math
- **面包屑集成**：选择使用主题内置面包屑还是兼容 SEO 插件
- **Schema 集成**：提供开关禁用主题基础 Schema
- **网站验证代码**：粘贴各大搜索引擎的验证 Meta 标签

### 3.10 性能优化

- **图片优化**：启用图片懒加载
- **资源控制**：控制 Gravatar 加载、禁用 Font Awesome 等
- **加载优化**：配置 DNS 预解析/预连接

### 3.11 高级功能

- **维护模式**：启用并配置网站维护模式页面
- **自定义代码**：注入自定义 CSS 和 JavaScript 代码
- **设置导入/导出**：管理主题设置数据

## 4. 内容创建与管理

### 4.1 创建文章与页面

1. 使用 WordPress 标准的文章(Posts) > 写文章(Add New)和页面(Pages) > 新建页面(Add New)
2. 利用右侧的文档(Document)设置面板配置文章格式、分类、标签、特色图片等
3. 利用右侧的区块(Block)设置面板调整当前选中区块的样式和属性

### 4.2 使用文章格式

对于标准文章，您可以在右侧的文档 > 状态与可见性 > 文章格式中选择不同的格式（如相册、视频、引语），主题会为这些格式提供特殊的样式展示。

## 5. 插件集成指南

### 5.1 集成 SEO 插件

1. 安装与配置插件：安装并启用 Yoast SEO 或 Rank Math
2. 主题设置：
   - 进入"主题设置 > SEO 设置"
   - 选择面包屑来源
   - 配置 Schema 集成
   - 添加验证代码

### 5.2 集成表单插件

1. 安装与配置插件：安装并启用您选择的表单插件
2. 创建表单：使用插件创建联系表单或其他表单
3. 嵌入表单：将插件生成的短代码粘贴到页面或小工具中

## 6. 高级应用

### 6.1 使用自定义 CSS/JS

1. 进入"主题设置 > 高级选项 > 自定义代码"
2. 在自定义 CSS 框中输入您的 CSS 规则
3. 在页头 JS 或页脚 JS 输入框中添加 JavaScript 代码

### 6.2 设置导入/导出

1. 备份设置：进入"主题设置 > 高级选项 > 导入/导出"，点击"导出设置"
2. 恢复设置：点击"导入设置"，选择之前导出的文件
3. 重置设置：可以将设置恢复到主题默认状态

## 7. 故障排除与 FAQ

### 7.1 常见问题解答

**Q: 为什么我保存了设置，前台没有变化？**
A: 1. 确保您点击了"保存更改" 2. 清除浏览器缓存 3. 如果您使用了缓存插件，请清除缓存 4. 检查是否有 CDN 缓存

**Q: 网站速度变慢了怎么办？**
A: 1. 安装并配置页面缓存插件 2. 优化图片大小 3. 在"主题设置 > 性能优化"中禁用不需要的资源加载 4. 考虑升级您的主机方案

### 7.2 基础故障排查步骤

1. 清除缓存：浏览器缓存、插件缓存、CDN 缓存
2. 检查插件冲突：暂时禁用除核心插件外的所有插件
3. 检查主题冲突：暂时切换到 WordPress 默认主题
4. 开启调试模式：在 wp-config.php 中设置 WP_DEBUG 为 true
5. 检查浏览器控制台：查看是否有 JavaScript 错误
6. 检查服务器环境：确保 PHP 版本、内存限制等符合要求
