# QIoooo 主题安装指南

## 系统要求

在安装 QIoooo 主题之前，请确保您的系统满足以下要求：

- WordPress 5.9 或更高版本
- PHP 7.4 或更高版本
- MySQL 5.6 或更高版本，或 MariaDB 10.1 或更高版本
- 至少 256MB 内存
- 至少 50MB 磁盘空间

## 安装步骤

### 方法一：通过 WordPress 后台安装

1. 登录 WordPress 后台
2. 进入"外观" > "主题"
3. 点击"添加新主题"
4. 点击"上传主题"
5. 选择下载的 QIoooo 主题包（.zip 文件）
6. 点击"立即安装"
7. 安装完成后点击"启用"

### 方法二：通过 FTP 安装

1. 解压下载的主题包
2. 使用 FTP 客户端连接到您的网站
3. 导航到 `wp-content/themes/` 目录
4. 上传 `qioooo` 文件夹
5. 登录 WordPress 后台
6. 进入"外观" > "主题"
7. 找到 QIoooo 主题并点击"启用"

## 初始设置

### 1. 基本设置

启用主题后，建议进行以下基本设置：

1. 进入"外观" > "自定义"
2. 设置站点标识（标题、标语、图标）
3. 配置菜单
4. 设置小工具

### 2. 主题设置

1. 进入"外观" > "主题设置"
2. 配置以下选项：
   - 主题颜色
   - 暗黑模式
   - 布局选项
   - 字体设置

### 3. 菜单设置

1. 进入"外观" > "菜单"
2. 创建主菜单和页脚菜单
3. 设置菜单位置

### 4. 小工具设置

1. 进入"外观" > "小工具"
2. 配置侧边栏小工具
3. 配置页脚小工具

## 常见问题

### 1. 主题安装失败

可能的原因：
- 文件权限问题
- 内存不足
- 上传文件损坏

解决方案：
1. 检查文件权限
2. 增加 PHP 内存限制
3. 重新下载主题包

### 2. 样式未正确加载

可能的原因：
- 缓存问题
- 文件路径错误
- 主题未正确激活

解决方案：
1. 清除浏览器缓存
2. 检查文件路径
3. 重新激活主题

### 3. 功能异常

可能的原因：
- 插件冲突
- 主题版本不兼容
- 设置错误

解决方案：
1. 停用其他插件测试
2. 更新主题到最新版本
3. 重置主题设置
